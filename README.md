# Trupti Yoga Studio

Official website for Trupti Yoga Studio, Thiruninravur, Chennai.

Live: <https://rajeshprasanth.github.io/truptiyoga.in/>
Repo: <https://github.com/rajeshprasanth/truptiyoga.in>

---

## Overview

A static, 8-page website built with plain HTML, CSS, and JavaScript — no
framework, no build tool, no server. Every page is self-contained and works
standalone (degrading gracefully where JavaScript is disabled).

### Pages

| Page          | File             | Notes                                          |
| ------------- | ---------------- | ---------------------------------------------- |
| Home          | `index.html`     | Hand-written                                    |
| About         | `about.html`     | Hand-written                                    |
| Classes       | `classes.html`   | Generated by `_tools/build_pages.py`           |
| Approach      | `approach.html`  | Generated by `_tools/build_pages.py`           |
| Gallery       | `gallery.html`   | Generated by `_tools/build_pages.py`           |
| Testimonials  | `testimonials.html` | Generated by `_tools/build_pages.py`        |
| FAQ           | `faq.html`       | Generated by `_tools/build_pages.py`           |
| Contact       | `contact.html`   | Generated by `_tools/build_pages.py`           |

> Do **not** hand-edit the generated pages — edit `_tools/` templates and
> re-run the build (see below).

## Directory layout

```
assets/
  css/style.css        Design system (palette tokens at top of file)
  js/site-data.js      Content layer — classes, faqs, gallery, testimonials
  js/main.js           Rendering + interactions (carousels, lightbox, FAQ)
  icons.svg            SVG sprite (all icons referenced as #id)
  img/                 Canonical source images (see pipeline)
    poses/ slider/ media/ testimonials/ awards/
    social/            Brand JPGs for the social handles
    favicon.png        trupti-logo.jpg  welcome.png
  img-gen/             Generated, optimised images served by the pages
    hero/  sections/  gallery/  testimonials/
_tools/
  make_images.py       Image pipeline → writes into assets/img-gen/
  build_pages.py       Page generator → writes the 6 inner pages
  shared-header.html   Header + mobile menu (used by generated pages)
  shared-footer.html   Footer + scroll-top button
  shared-scripts.html  Script/font includes
```

## Design constraints

- **The palette is frozen.** `:root` tokens in `assets/css/style.css`
  (`--primary`, `--accent`, `--sage`, `--bg`, `--surface`, `--ink`, ...) must
  not change — the brand identity depends on them.
- Fonts: Cormorant Garamond / EB Garamond / Poppins (Google Fonts).
- **Do not invent content.** Never fabricate testimonials, student names,
  class timings, fees, or policies. Use "To be confirmed" → better, omit, or
  "please contact the studio" for anything not confirmed.
- Pages must keep their structure: one `<h1>`, one `<main id="main">`, no
  duplicate ids.

## Image pipeline

`assets/img-gen/` is the folder the site actually references. It is generated
from the canonical sources in `assets/img/`:

```
python3 _tools/make_images.py
```

| Output | Source |
| ------ | ------ |
| `hero/hero.jpg`, `hero-md.jpg` | `assets/img/slider/sliders.png` (2048×768 banner) |
| `sections/welcome.jpg` | `assets/img/welcome.png` (fallback: `poses/13.png`) |
| `sections/story.jpg`, `approach.jpg`, `teacher.jpg` | `poses/12.png`, `poses/5.png`, `poses/6.png` |
| `sections/award.jpg`, `gallery/gal-award.jpg` | `awards/award-photo.jpg` |
| `gallery/gal-pose-*`, `pose-full-*` (16 each) | `poses/*.png` |
| `gallery/gal-media-01..07` | `media/media-1..7.jpg` |
| `testimonials/testimonial-*` | auto-discovered `img/testimonials/*.{jpg,png}` |

### ⚠️ External prune hazard

An **external process periodically rewrites `assets/img/`** and can delete
files. `assets/img-gen/` was placed as a sibling so it survives. After any
prune: re-run `python3 _tools/make_images.py` to regenerate. If a source file
is gone, `make_images.py` skips it and prints `SKIP (missing source)`.

## Page build

```
python3 _tools/build_pages.py
```

Regenerates the 6 inner pages from `shared-header.html`, `shared-footer.html`,
`shared-scripts.html` and the embedded section templates. `index.html` and
`about.html` are hand-authored and not overwritten.

After a build, verify nothing broke:

```
python3 _tools/qa.py          # if present; otherwise spot-check with grep
```

## Content updates

### Classes / FAQs / wording
Letters in `assets/js/site-data.js` (`classes`, `faqs`, `audience`,
`achievements`, `events`, `testimonials`, `gallery`). Class cards show
Duration/Schedule only when a real value is set.

### Adding a testimonial
1. Drop the screenshot into `assets/img/testimonials/` (any filename).
2. Run `python3 _tools/make_images.py` (auto-generates an optimised copy).
3. Add one line to the `testimonials` array in `assets/js/site-data.js`:
   ```js
   { src: "assets/img-gen/testimonials/testimonial-<name>.jpg", alt: "Student feedback shared with Trupti Yoga Studio" }
   ```

### Gallery items
Edit the `gallery` array in `site-data.js` (thumb + full `src`, `cat`, alt,
caption). Filters: `poses`, `press`, `achievement`.

### Icons
Icons are `<use href="assets/icons.svg?v=brand#i-name">`. Add/swap a symbol in
`assets/icons.svg`. The `?v=` query is a cache-buster — bump it after changing
the sprite. The 4 social handles in the footer are JPGs in `assets/img/social/`
(Photoshop/any editor can replace them; same filename).

## Publishing (GitHub Pages)

The repo serves Pages directly from the `main` branch, root path. To publish:

```
git add -A
git commit -m "describe change"
git push origin main
```

GitHub builds Pages automatically; the URL is
`https://rajeshprasanth.github.io/truptiyoga.in/`.

**Note:** The canonical / OpenGraph / sitemap URLs still point to
`https://truptiyoga.in/`. If a custom domain is ever attached to Pages, update
`robots.txt`, `sitemap.xml`, the `canonical` og:image/JSON-LD lines in the
templates, and the JSON-LD block in `index.html`/`about.html` accordingly.
